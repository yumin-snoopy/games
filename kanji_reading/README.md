# 難読漢字チャレンジ

漢字の読み方を選ぶ四択クイズです。公開ページは https://yumin-snoopy.github.io/games/kanji_reading/ です。

## 問題

現在は73問です。漢字の表記と読みのみを収録し、辞典の意味・解説文・例文や画像は転載していません。初期版で独自に選定した語のうち、後の確認版でも同じ読みが残ったものを採用しました。特定の辞典の「難読」欄からまとめて追加した語は含めていません。

解答後の「この漢字を外部で調べる」は、その漢字をGoogleで検索するリンクです。検索先の文章や検索結果はゲームに取り込みません。検索結果の正確性は保証されないため、必要に応じて複数の辞典で確認してください。

難易度は遊びやすさの目安で、漢検の正式な出題級を表すものではありません。

## 開発者向け

`questions.js` の問題データには `id`、`kanji`、`reading`、`category`、`difficulty` を記録します。誤答候補は同じジャンルの別の読みから生成します。問題追加時は読みを確認し、他人が作成した問題一覧をまとめて転記しないでください。

`node validate.js` で重複、必須項目、分類、四択を検査できます。読みの正確性そのものは機械検査では確定できません。
