# 難読漢字チャレンジ

## 概要

漢字の読みを選ぶ四択クイズです。全500問から難易度とジャンルを選んで挑戦できます。

## 主な機能

- 難易度・ジャンル別の出題
- 得点・連続正解・残りミスの表示
- 間違えた問題の復習と過去最高記録

## 使い方

難易度とジャンルを選んで開始します。読みを選び、3問間違えるまで挑戦します。結果画面から間違えた問題を復習できます。
