# 難読漢字チャレンジ

GitHub Pages の `/kanji_reading/` で遊べる、HTML・CSS・JavaScript だけの四択ゲームです。ゲーム自体は外部通信を必要としません。回答後に辞典の出典リンクを開けます。

## 問題の選定

2026年10月22日現在、出題対象は108問です。日本の地名は今回すべて外しました。旧問題も読みの出典を記録できたものだけ残しています。複数の読みで正解が分かれそうな問題は採用していません。今回の新規追加18問はすべて動物・鳥・魚です。

各問題の `source` は、表記と読みを確認したコトバンクの辞典ページを指します。小学館『デジタル大辞泉』の個別項目または漢字の「難読」欄を主に参照しました。多義語でも対象の動物などを明示すれば成立する場合は、解説に補足しています。

## 問題の追加

`questions.js` の `QUESTION_DATA` に、重複しない `id`、`kanji`、`reading`、`category`、`difficulty`、`explanation`、`source` を持つ問題を追加します。旧IDは端末内の復習記録と対応するため再利用しません。誤答候補は同ジャンルの別の読みから自動生成します。複数の有効な読みがある表記は、問題文と解説だけで答えを一意にできる場合を除いて採用しません。

`node kanji_reading/validate.js` でID、問題、選択肢の重複、正解、分類、必須項目、出典URLを検査できます。URLの存在、辞典との一致、語義の正確さは機械検査では証明できないため、追加時に各項目を人の目で確認してください。
