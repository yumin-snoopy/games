# 難読漢字チャレンジ

漢字の読み方を選ぶ四択クイズです。公開ページは https://yumin-snoopy.github.io/games/kanji_reading/ です。

## 問題

現在は500問です。漢字の表記と読みのみを収録し、辞典の意味・解説文・例文や画像は転載していません。難易度とジャンルはゲーム用の分類です。難易度は漢検の正式な出題級を表しません。

読みの確認では複数の辞典ページを参照しました。旧版の出典記録は非公開のバックアップに残しています。各語の読みには異説や別の読みがあり得るため、出題ジャンルを示し、調べるためのリンクを解答後に表示します。

解答後の「この漢字を外部で調べる」は、その漢字をGoogleで検索するリンクです。検索先の文章や検索結果はゲームに取り込みません。

## 開発者向け

`questions.js` の問題データには `id`、`kanji`、`reading`、`category`、`difficulty` を記録します。誤答候補は同じジャンルの別の読みから生成します。問題追加時は読みを確認し、他人が作成した問題一覧や辞典の解説文を転載しないでください。

`node validate.js` で重複、必須項目、分類、四択を検査できます。読みの正確性そのものは機械検査では確定できません。
