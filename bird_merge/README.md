# ことりマージ

## 概要

鳥を落とし、同じ鳥どうしをくっつけて育てるゲームです。物理演算を使った動きが楽しめます。

## 主な機能

- 鳥の合体と成長ずかん
- 得点・ベストスコアの表示
- マウス・キーボード・タッチ操作と音の切り替え

## 使い方

落とす位置を決めて鳥を落とします。同じ鳥を重ねて大きく育てます。鳥が上の線を超えた状態で続くと終了です。

## 起動・体験

[**ことりマージを開く**](https://yumin-snoopy.github.io/games/bird_merge/)
