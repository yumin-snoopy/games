# Bird Match Puzzle

8×8の鳥の3マッチパズルです。ブラウザだけで遊べます。

## 遊び方

- 鳥をクリック・タップしてから、上下左右の隣の鳥を選ぶと交換します。
- PCではドラッグ、スマートフォンではスワイプでも交換できます。短すぎる移動や斜めの移動は交換しません。
- 縦か横に同じ鳥が3羽以上並ぶと消え、上の鳥が落ちて補充されます。補充で再びそろうと連鎖します。そろわない交換は元に戻ります。
- 時間制限はありません。有効な交換がなくなるまで高いスコアを目指します。
- 交換できる場所がなくなったらゲーム終了です。最終スコア・最大コンボ・消した鳥の合計数を表示します。

## 鳥の種類とスペシャル鳥

「鳥の種類」は3種類（かんたん）・4種類（ふつう、初期設定）・5種類（むずかしい）から選べます。種類を変更すると新しいゲームが始まります。種類が少ないほど連鎖しやすくなります。

1回の交換から5連鎖目が発生すると、その回に消えたマスの1つに「虹の卵」が出現します。1回の連鎖では最大1個、盤面上では最大3個です。3個あるときもコンボ得点は加算されます。

虹の卵をクリック・タップすると、隣の鳥との交換を案内し、交換可能な隣のマスを強調します。通常の鳥と交換すると、その種類の鳥を盤面上からすべて消し、虹の卵自身も消費します。その後も落下・補充・連鎖が進みます。虹の卵同士の交換は無効です。

3羽で300点、4羽で500点、5羽以上は1羽増えるごとに300点追加します。連鎖時は「(連鎖数 - 1) × 消した羽数 × 50点」を追加します。虹の卵の効果では消した鳥1羽につき100点です。

「NEW GAME」または「もう一度遊ぶ」は、選んだ鳥の種類を維持してスコア・コンボ・最大コンボ・消去数を初期化します。時間制限のコードはコメントとして残しています。
