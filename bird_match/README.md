# 鳥あわせパズル（Bird Match Puzzle）

## 概要

隣り合う鳥を入れ替え、同じ鳥を3羽以上そろえて消すパズルです。

## 主な機能

- 3・4・5種類から鳥の種類を選択
- 得点・コンボの表示
- 5連鎖で現れる虹の卵

## 使い方

鳥を2羽選ぶか、上下左右にドラッグして入れ替えます。3羽以上をそろえ、動かせる場所がなくなるまで得点を伸ばします。
