# Bird Match Puzzle

## ゲーム概要

鳥をテーマにした、8×8の3マッチパズルです。6種類の鳥を入れ替えて、同じ鳥を縦または横に3羽以上そろえます。ブラウザだけで動作し、インストールは不要です。

## 遊び方・操作方法

1. PCでは鳥をクリック、スマートフォンではタップして1羽目を選びます。
2. 上下左右に隣接する鳥をもう1羽選ぶと、2羽が入れ替わります。
3. 同じ鳥が縦または横に3羽以上並ぶと消え、上の鳥が落ちて新しい鳥が補充されます。再びそろうと自動で連鎖します。
4. 3羽以上そろわない交換は元に戻ります。「NEW GAME」で盤面とスコアを初期化できます。

開始時にそろった鳥がない、かつ有効な交換が1つ以上ある盤面を作ります。途中で有効な交換がなくなった場合は、スコアを保って盤面を作り直します。

3羽で300点、4羽で500点、5羽以上は1羽増えるごとに300点追加します。連鎖時は消えた鳥1羽あたり50点の追加点が入り、COMBOに連鎖数を表示します。

## 使用技術

HTML・CSS・JavaScriptのみ。外部ライブラリは使用していません。右クリックと主な開発者ツール用ショートカットは簡易的に抑止していますが、ソースの完全な保護ではありません。
