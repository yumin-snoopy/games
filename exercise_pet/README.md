# どうぶつと一緒に3分エクササイズ

オリジナルのシマエナガ風キャラクターの動きを見ながら、ジャンプせず静かに体を動かすブラウザアプリです。インストール・ログイン・音声は不要です。

## 使い方

1. 「3分エクササイズをはじめる」を押します。
2. 3秒のカウントダウン後、画面中央の動きに合わせて運動します。
3. 今の運動の残り時間が30秒からカウントダウンし、6種目が自動切り替えされます。コース全体の残り時間も表示します。一時停止と再開ができます。
4. 3分完了すると記録されます。「運動記録を見る」で日別履歴と今月のカレンダーを確認できます。

## 運動メニュー

「静かに全身3分コース」：その場で軽く足踏み、左右にサイドステップ、両腕の上げ下げ、かかとの上げ下げ、浅いスクワット、ゆっくり足踏み（各30秒、計180秒）。痛みやめまいを感じたら中止し、スクワットは深くしゃがまないでください。

## 記録と技術

完了時のみ、実施日時・コースID・コース名・実施秒数・完了状態を `localStorage` に保存します。途中終了は記録しません。同じ日の複数回実施を個別に保存し、合計に反映します。データは利用中のブラウザに保存され、ブラウザのデータ消去で失われる場合があります。

HTML・CSS・JavaScript・SVGのみで構成され、外部ライブラリは使用しません。運動とコースは `app.js` の `EXERCISES`・`COURSE` にまとめてあり、追加しやすい構成です。
