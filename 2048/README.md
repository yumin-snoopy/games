# 2048

## 概要

同じ数字のタイルをくっつけ、2048を目指すパズルゲームです。数字は選んだ方向へまとめて動きます。

## 主な機能

- 矢印キー・画面ボタン・スワイプでの操作
- 得点とベストスコアの表示
- 新しいゲームと遊び方の案内

## 使い方

矢印キーなどでタイルを動かし、同じ数字を合体させます。動かせる場所がなくなる前に2048を作ります。

## 起動・体験

[**2048を開く**](https://yumin-snoopy.github.io/games/2048/)

## 使用技術

HTML・CSS・JavaScript
