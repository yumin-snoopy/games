# Lights Out（ライトアウト）

5×5のライトをすべて消す、一人用のパズルゲームです。HTML・CSS・JavaScriptだけで動作し、外部ライブラリは使いません。

## 遊び方

ライトを1つ押すと、そのライトと上下左右のライトの点灯・消灯が反転します。25個すべてを消灯するとクリアです。

初期盤面は、全消灯の状態からランダムな9～15か所を押して作るため、必ず解けます。経過時間は最初の1手から計測します。

## 操作方法

- PC：マスをクリックします。キーボードでは Tab キーでマスを選び、Enter または Space キーで押せます。
- スマートフォン：マスをタップします。
- **最初から**：同じ初期盤面で、手数と時間をリセットします。
- **新しいゲーム**：別の盤面を作ります。クリア後の **もう一度遊ぶ** も同じ動作です。
