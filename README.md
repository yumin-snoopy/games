現在は、テトリスとオセロを収録しています。

## ゲーム一覧

### テトリス

ブラウザで遊べるテトリスです。

[テトリスを開く](./テトリス/index.html)

### オセロ

ブラウザで遊べるオセロです。

[オセロを開く](./オセロ/index.html)
