# とりとり大作戦

鳥をテーマにしたオリジナルの横方向ラインディフェンスゲームです。明るい「はじまりの草原」で、1ステージを最後まで遊べます。既存ゲームのキャラクター・画像・名称・デザイン・音楽は使っていません。風景と巣はCanvasで描き、キャラクターは端末標準の絵文字を使用しています。音楽・効果音はありません。

**[ゲームを遊ぶ](https://yumin-snoopy.github.io/games/bird_battle/)**

## 遊び方

1. 「作戦スタート」を押します。
2. 毎秒17ずつ増えるエサを使い、下の鳥ボタンをクリック／タップして出撃させます。
3. 鳥は左の巣から右へ進み、相手や相手の巣に近づくと自動で停止・攻撃します。
4. 右の巣のHPを0にすると **VICTORY！**、自分の巣のHPが0になると **GAME OVER**。終了後は「もう一度遊ぶ」で再挑戦できます。

キーボードでは **1：すずめ / 2：ふくろう / 3：わし / P：一時停止・再開**。一時停止ボタンもあります。別のタブへ移動すると自動で一時停止します。エサ不足、出撃後のクールタイム、仲間18羽の上限では出撃ボタンが無効になります。味方・相手・双方の巣にHPバーがあります。

すずめで前線を支えながら、ふくろうやわしを送りましょう。相手を倒すとエサが少し増えます。相手の増援は150秒で終了します。目安は2〜5分で、鳥の組み合わせや出撃頻度によって変わります。制限時間はありません。

## ファイル構成

```text
bird_battle/
├─ index.html       # ゲーム画面・操作説明
├─ style.css        # PC・スマートフォンのレイアウト
├─ script.js        # 設定・状態・戦闘・描画・UI
├─ images/
│  └─ .gitkeep      # 将来のオリジナル画像の置き場
└─ README.md
```

HTML / CSS / JavaScriptのみ。サーバー・データベース・外部ライブラリ・CDNは不要です。GitHub Pages、またはローカルの`index.html`を開くだけで動作します。セーブ・育成・ガチャ・ログインなどはありません。

## 拡張方法

- `script.js`先頭の`BIRDS`と`ENEMIES`にキャラクター設定を集約しています。`BIRDS`へ追加すると出撃ボタンも自動生成されます。キーボード1〜3は現在の最初の3種類に対応します。
- `hp` / `attack` / `speed` / `interval`で戦闘値を変更できます。鳥は`cost`と`cooldown`、相手は`reward`も設定します。
- `image: null`を`image: "images/sparrow.png"`のように変更すると、自作画像を使えます。読み込みに失敗した場合は絵文字に戻ります。キャラクター画像は正方形の透明PNG/WebPを推奨します。
- 相手の出現順は`Battle.spawnEnemy()`の`sequence`、巣のHPやエサは`SETTINGS`で変更できます。
- `Battle`は状態・戦闘、`Unit`はユニット、`initializeGame()`は表示と操作を担当します。戦闘は秒単位の固定ステップで動作し、一時停止や再挑戦で古いタイマーは残りません。
- 移動距離は論理座標1200×440基準。画面幅に合わせて描画されます。スマートフォンは縦向きでも操作でき、横向きなら戦場が見やすくなります。
