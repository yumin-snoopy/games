# とりとり大作戦

## 概要

エサをためて鳥を送り出し、相手の巣を目指すゲームです。鳥は出撃後、自動で進んで戦います。

## 主な機能

- すずめ・ふくろう・わしの出撃
- エサと巣の体力の表示
- 一時停止とキーボード操作

## 使い方

「作戦スタート」を押し、エサがたまったら鳥のボタンで出撃させます。自分の巣を守りつつ、相手の巣の体力を0にします。
