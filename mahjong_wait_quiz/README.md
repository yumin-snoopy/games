# 麻雀・待ち牌当てクイズ

## 概要

13枚の門前テンパイ形から、アガれる牌をすべて選ぶクイズです。一般形・七対子・国士無双を扱います。

## 主な機能

- 初級・中級・上級の選択
- 待ち牌の複数選択と答え合わせ
- ヒントと次の問題

## 使い方

難易度を選び、手牌を見て待ち牌をすべて選択します。「答え合わせ」で正解を確認します。

## 起動・体験

[**麻雀・待ち牌当てクイズを開く**](https://yumin-snoopy.github.io/games/mahjong_wait_quiz/)

## 使用技術

HTML・CSS・JavaScript

## ライセンス・外部ライブラリ

外部ライブラリは使用していません。このゲーム自体のライセンスは明示されていません。役・点数・フリテン・場に見えている牌は判定しません。
