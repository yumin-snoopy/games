# シマエナガの色わけロジック

ブラウザで遊べる、シマエナガを配置するロジックパズルです。`index.html` を開くだけで動作し、外部ライブラリは使いません。

## 遊び方

各行、各列、同じ色のエリアにシマエナガを1羽ずつ置きます。シマエナガ同士は上下左右・斜めの8方向で隣接できません。マスをクリックまたはタップすると「空白 → シマエナガ → × → 空白」と切り替わります。×は自分用の目印で、クリア判定には影響しません。

レベル1〜10は4×4〜8×8を2レベルずつ進み、各レベルに3問あります。後半のサイズほど置き方の候補が増えます。どの問題も8方向の隣接禁止を含むルールで答えが1つです。「別の問題にする」は今の問題とは違う問題をランダムに選びます。「この問題をリセット」で配置を消せます。ヒントは正しい配置の1マスを示します。最後のレベルとベストタイムはブラウザに保存します。

## ファイル

- `index.html`：画面構成
- `style.css`：見た目とスマートフォン表示
- `script.js`：問題、操作、判定、記録
