# シマエナガの色わけロジック

## 概要

各行・各列・各色エリアに1羽ずつ、互いに隣り合わないようシマエナガを置くパズルです。全10レベルあります。

## 主な機能

- 10レベルの選択
- マスの空白・シマエナガ・×の切り替え
- ヒント・リセット・別の問題

## 使い方

レベルを選び、各マスを押して印を切り替えます。行・列・色エリアに1羽ずつ置き、斜めも含めて隣り合わない配置を探します。
