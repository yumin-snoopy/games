# リバーシ

## 概要

相手の石をはさんで裏返し、最後に石の数を競うゲームです。人同士またはCPUと対局できます。

## 主な機能

- 対人・CPU対局と5段階のCPU強さ
- 置ける場所・得点・対局ログの表示
- ヒント・パス・投了と盤面の見た目の変更

## 使い方

設定を選び「新規対局」を押します。黄色い枠のマスへ石を置き、相手の石をはさんで裏返します。
