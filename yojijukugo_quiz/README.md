# 四字熟語クイズ

ブラウザだけで動く四択クイズです。102語を収録し、各語に穴埋め・意味・読み方の3形式を用意しています（計306問）。外部APIやCDNは使いません。

問題データは `data.js` に「熟語・読み・意味・難易度」を一行ずつ記録しています。実在する語と読みの確認には[四字熟語辞典オンライン](https://yoji.jitenon.jp/)と[JMdict由来の四字熟語一覧](https://github.com/faanau/yojijukugo-db)を参照し、意味はクイズ向けに短く記述しています。データの自動検証は構造・重複・選択肢候補を対象とし、辞書との意味の一致までは自動判定しません。

`node validate.js` で問題データの構造、重複、難易度別件数、穴埋めの誤答候補を確認できます。
