# 四字熟語クイズ

## 概要

四字熟語の前半または後半を選ぶ四択クイズです。200語・400問を収録し、1問間違えると終了します。

## 主な機能

- 開始難易度の選択
- 文字サイズの切り替えと自己ベスト
- 間違えた問題の復習

## 使い方

難易度を選んで始め、空欄に入る語を選びます。間違えたら結果を確認し、復習できます。
