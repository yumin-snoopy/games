# 四字熟語クイズ

ブラウザだけで動く四択クイズです。200語を収録し、各語に前半・後半の穴埋め問題を用意しています（計400問）。1問でも間違えたら、正解の四字熟語と読みを表示して終了します。正解時は解説を表示しません。外部APIやCDNは使いません。

問題データは `data.js` に「熟語・読み・難易度」を一行ずつ記録しています。語と読みの確認には[四字熟語辞典オンライン](https://yoji.jitenon.jp/)と[JMdict由来の四字熟語一覧](https://github.com/faanau/yojijukugo-db)を参照しています。説明文や意味の問題は収録していません。

`node validate.js` で問題データの構造、重複、難易度別件数、穴埋めの誤答候補を確認できます。
