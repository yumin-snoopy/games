# 数字つなぎパズル

## 概要

同じ数字を、交差しない線でつなぐパズルです。上下左右へ線を伸ばして全組をつなぎます。

## 主な機能

- LEVEL 1〜5 と新しい問題
- ドラッグ・スワイプでの線引き
- ヒント・やり直し・時間表示

## 使い方

レベルを選び、数字から同じ数字まで線を伸ばします。線を消すときは数字を押します。

## 起動・体験

[**数字つなぎパズルを開く**](https://yumin-snoopy.github.io/games/number_link/)
