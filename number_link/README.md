# Number Link Puzzle（数字つなぎパズル）

同じ数字を、交差しない線でつなぐブラウザ用パズルゲームです。HTML・CSS・JavaScriptのみで動作し、外部ライブラリは使いません。

## ルールと操作

- 同じ数字同士だけを上下左右の線で接続します。斜めには進めません。
- 別の数字や線があるマスは通れず、線同士は交差しません。
- 数字からマウスでドラッグ、または指でスワイプします。引いた線を消すときは、その数字をクリック・タップします。
- すべてのペアをつなぐとクリアです。盤面の全マスを埋める必要はありません。
- 「ヒント」は未接続のペアを一組だけ強調します。正解の線は表示しません。
- 「やり直す」は同じ問題を初期状態へ戻し、「新しい問題」は同じレベルの別配置を生成します。

## レベル

| レベル | 盤面 | 数字 | 生成時の最低経路長 | 特徴 |
| --- | --- | --- | --- | --- |
| LEVEL 1 | 5×5 | 1〜3 | 4マス | 基本操作に慣れる |
| LEVEL 2 | 6×6 | 1〜4 | 6マス | 曲がる経路が増える |
| LEVEL 3 | 7×7 | 1〜5 | 7マス | 離れた数字をつなぐ |
| LEVEL 4 | 8×8 | 1〜6 | 9マス | 経路の干渉が増える |
| LEVEL 5 | 9×9 | 1〜7 | 10マス | 長い迂回と順序を考える |

## 問題生成と解答可能性

`generator.js` の `LEVELS` に盤面サイズ、数字数、経路長・距離・曲がりなどの基準を定義しています。最初に盤面全体を通る一筆書きの経路を作り、端点の組み替え操作で形をランダム化します。その経路から互いに重ならない複数の区間を選び、各区間の両端だけを数字として表示します。LEVEL 3以上では両端が同じ行・列になる組を除外し、LEVEL 4・5では大きく迂回する組を複数要求します。

表示前に内部の解答経路を検査し、すべての数字が一組ずつあること、各経路が上下左右の隣接マスだけで進むこと、盤面内に収まること、経路同士がマスを共有しないことを確認します。条件を満たさない候補は破棄して再生成します。この検査済み経路自体が解答の証明になります。LEVEL 3以上では単純な最短経路を順に引く方法で解ける候補も除外します。別問題を要求した直前の問題と端点配置が同じ場合も再生成します。

高難度は生成時の経路長・曲がり・迂回の基準で調整しています。実際の解答時間や一意解は保証していません。
