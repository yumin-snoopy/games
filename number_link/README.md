# Number Link Puzzle（数字つなぎパズル）

同じ数字のペアを、上下左右に伸びる線でつなぐブラウザ用パズルゲームです。外部ライブラリは使わず、HTML・CSS・JavaScriptだけで動作します。

## ルール

- 同じ数字同士だけを接続します。
- 線は上下左右に進み、斜めには進めません。
- 他の数字や別の線があるマスは通れず、線同士は交差しません。
- すべてのペアを接続するとクリアです。盤面の全マスを埋める必要はありません。

## 操作方法

数字のマスからマウスでドラッグ、または指でスワイプして、同じ数字まで線を伸ばします。引いた線を消してやり直すときは、その数字をクリック・タップします。「ヒント」は未接続の数字のペアを強調します。時間制限はありません。

## ステージ

| ステージ | 盤面 | ペア | 内容 |
| --- | --- | --- | --- |
| LEVEL 1 | 5×5 | 1〜3 | 基本操作に慣れる入門配置 |
| LEVEL 2 | 6×6 | 1〜4 | 線の順序を考える配置 |
| LEVEL 3 | 7×7 | 1〜5 | 迂回経路を見つける配置 |

ステージは `script.js` の `STAGES` に盤面サイズと数字の両端を定義しています。各ステージには開発時に検証済みの解答経路も併記しており、追加ステージの解答可能性を確認できます。将来ランダム生成を加える場合も、生成後に経路検証を通す構造にできます。
