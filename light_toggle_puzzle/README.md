# ライト消しパズル

## 概要

5×5のライトをすべて消すパズルです。押したマスと上下左右のライトが切り替わります。

## 主な機能

- 手数・時間・ヒント回数の表示
- ヒント・やり直し・新しい問題
- クリア結果の表示

## 使い方

マスを押してライトを切り替えます。すべて消せばクリアです。迷ったらヒントを使います。

## 起動・体験

[**ライト消しパズルを開く**](https://yumin-snoopy.github.io/games/light_toggle_puzzle/)

## 使用技術
