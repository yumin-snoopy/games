# 数字ならべ計算パズル

## 概要

数字の札を空欄に置き、指定の答えになる式を完成させるゲームです。1回10問で時間制限はありません。

## 主な機能

- 3段階の難易度
- 札のタップ・ドラッグ操作
- ヒント・答え・結果の表示

## 使い方

難易度を選び、札を押して空欄を押すかドラッグして並べます。「答え合わせ」で計算結果を確認します。
