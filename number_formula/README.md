# 数字ならべ計算パズル

[公開ページ](https://yumin-snoopy.github.io/games/number_formula/)

数字の札を選んで式の空欄を押すか、札を空欄へドラッグして配置します。配置済みの数字を押すと札の置き場に戻ります。すべて置いたら「答え合わせ」を押してください。正解まで何度でも置き直せます。「ヒント」は数字を1枚固定し、「答えを見る」は正解例を示します。1回10問で、時間制限はありません。

難易度は、やさしい（札3枚、＋・−）、ふつう（札3枚、×と＋または−）、難しい（札4枚、＋・−・×と括弧）です。

計算は括弧の中、掛け算、足し算・引き算の順に行います。足し算・引き算が続くときは左から計算します。
